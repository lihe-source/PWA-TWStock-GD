股序｜資料與隱私說明

版本 1.0.0 · 2026-10-29

資料用途

本程式提供台股公開資料查詢、篩選、分類與觀察筆記。行情使用證交所及櫃買中心官方公開資料。程式沒有自動交易、廣告追蹤或分析追蹤碼。

個人記錄

分類、筆記、條件與快照先保存在裝置的 IndexedDB。你連接 Google Drive 後，這些記錄會同步到你透過 Google Picker 選取的資料夾。不會將私人記錄寫入公開 GitHub repository 或傳給本工具的其他使用者。

Google 授權

程式使用 drive.file 權限，以建立、讀取與更新由本程式建立或你明確授權的檔案。帳號信箱僅用於顯示連線狀態與防止不同帳號混用本機資料。存取 token 只保留在分頁記憶體，不寫入匯出備份或原始碼。

保存與刪除

你的資料保存在你自己的裝置與 Google Drive。刪除筆記或分類會以同步刪除記錄傳播；舊版本仍可能存在於變更檔與備份中。若要完全移除，請先備份需要保留的內容，再在 Google Drive 刪除本程式資料夾，移除 Google 帳號中的程式存取權，並清除各裝置此網站的資料。執行這些步驟會失去對應記錄。

第三方連線

連接 Google 時會載入 Google Identity Services 與 Google Picker；它們依 Google 政策運作。網站檔案由 GitHub Pages 提供。依你的設定，公開行情由你的 GitHub Actions 下載；程式不收集你的 Google 密碼。
